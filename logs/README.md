# Execution records

[RUNLOG.md](RUNLOG.md) preserves the full historical command/output record, including failed attempts and progress output. It is an audit trail, not the primary results summary; start with the root README and linked evaluation files.

Public copies replace machine-specific paths with `<REPO>`, `<BLANK_REPO>`, or `<COMPUTE_HOME>`, and the previous HF destination with `<PREVIOUS_HF_ACCOUNT>`. These placeholders record redaction, not a claim that old commands used the current account. Measurements and failures are retained. Original copies are preserved locally in the ignored `.local_archive/` folder. Historical paths inside commands may describe the old layout.

The active artifact destination is `silvix9/jlens-subliminal-artifacts`. No other account is used for new uploads.
